# Data

`train.csv` is the training portion of the dataset described in the project README: the hourly records of 2011 to 2014. The committee keeps 2015 private and uses it only for grading.

Source: Kaya, H., Tüfekci, P. and Uzun, E. (2019). Predicting CO and NOx emissions from gas turbines: novel data and a benchmark PEMS. Turkish Journal of Electrical Engineering and Computer Sciences, 27(6), 4783–4796. DOI 10.3906/elk-1807-87. Dataset: Gas Turbine CO and NOx Emission Data Set, UCI Machine Learning Repository, DOI 10.24432/C5WC95.
